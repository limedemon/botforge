# Конструктор Telegram-ботов

Бот, внутри которого человек мышкой собирает своего бота: раскладывает блоки
на полотне, соединяет их стрелками, вставляет токен своего бота от @BotFather —
и тот сразу начинает работать.

Весь проект — один файл `main.py`. Полотно редактора лежит внутри него же.

## Как это устроено

Ботов клиентов не запускается по отдельной программе на каждого. Клиентский
бот — это просто запись в базе, а исполняет её один общий движок. Поэтому
сервис нужен ровно один, сколько бы ботов на нём ни сделали.

* `/` — полотно (мини-апп внутри Telegram)
* `/health` — проверка, что сервис жив
* `/hook/main/<секрет>` — сообщения самому боту-конструктору
* `/hook/<номер проекта>/<секрет>` — сообщения ботам клиентов

## Что нужно перед запуском

1. **Бот-конструктор.** В Telegram напишите @BotFather, отправьте `/newbot`,
   придумайте имя. В ответ придёт токен вида `1234567:AA...`.
2. **База данных.** Бесплатный проект на [neon.tech](https://neon.tech).
   Скопируйте строку подключения, она начинается на `postgresql://`.

## Запуск на Render

1. Зайдите на [render.com](https://render.com), нажмите **New → Web Service**
   и подключите этот репозиторий.
2. Root Directory оставьте пустым, Build Command —
   `pip install -r requirements.txt`, Start Command — `python main.py`.
3. В Environment Variables добавьте:
   * `BOT_TOKEN` — токен бота-конструктора;
   * `DATABASE_URL` — строка подключения от Neon.
4. Нажмите **Create Web Service** и дождитесь статуса *Live*.
5. Напишите своему боту `/start` — придёт кнопка «Открыть конструктор».

Таблицы в базе создадутся сами при первом запуске.

## Переменные окружения

| Переменная     | Обязательна | Зачем                                                          |
|----------------|-------------|-----------------------------------------------------------------|
| `BOT_TOKEN`    | да          | Токен бота-конструктора от @BotFather                           |
| `DATABASE_URL` | нет         | Postgres (Neon). Без неё данные лягут в файл рядом с `main.py`  |
| `PUBLIC_URL`   | нет         | Адрес сервиса. На Render подставляется сам                       |
| `PORT`         | нет         | Порт. На Render подставляется сам                                |
| `TELEGRAM_API` | нет         | Другой адрес Bot API, если основной недоступен                   |

## Как пользоваться полотном

Блок можно взять и перетащить. Полотно двигается пальцем, приближается щипком
(на компьютере — колесом мыши) и кнопками в углу; `⤢` уместит всю схему в экран.

**Соединить блоки.** Коснитесь кружка справа у нужного выхода — он станет
красным — затем коснитесь блока, куда вести стрелку. Чтобы убрать стрелку,
выберите тот же блок, куда она уже ведёт. Промах по пустому полю — отмена.
Тот же выбор есть и в панели настроек, списком.

**Правка.** Касание блока открывает панель со всеми полями: слева на
компьютере, снизу на телефоне. Рядом с выбранным блоком появляются кнопки
«скопировать» и «удалить».

**Кнопка `+`** внизу слева добавляет блок, **`☰`** сверху справа — меню
(сохранить, разложить блоки, настройки бота).

## Какие бывают блоки

| Блок | Что делает |
|---|---|
| **Сообщение** | Пишет текст, может приложить картинку и файл по ссылке, показать кнопки |
| **Ввод** | Задаёт вопрос, ждёт ответ и запоминает его под именем |
| **Ключевые слова** | Точка входа: срабатывает на слова в сообщении — точно или по вхождению |
| **События** | Точка входа: первое сообщение, неизвестная команда, блокировка бота, присланное фото/видео/файл/место/голосовое, любое сообщение |
| **Действие** | Записать или удалить переменную, поставить или снять тег, прислать вам заявку |
| **Условие** | Развилка «да / нет» по переменной или тегу |
| **Рандом** | Случайный выбор из вариантов с весами |
| **Таймер** | Подождать минуты, часы или дни и продолжить |
| **Заметка** | Комментарий на полотне, ботом не исполняется |

Стартовый блок отмечен зелёной наклейкой — с него бот начинает по `/start`.

Ответы подставляются в текст: `Спасибо, {имя}!`. Всегда есть `{name}` и
`{username}` — имя и ник из Telegram.

## Чего нет и почему

* **Цвет кнопок** — в Telegram кнопки всегда одинаковые, цвет задать нельзя.
* **Подписка на сообщество** — у ботов Telegram нет сообществ. Вместо этого
  есть события «заблокировал» и «разблокировал бота».
* **Google Таблицы** — нужны ключи доступа Google, отдельная работа.
* **Несколько сценариев** в одном боте и блок «Запуск сценария».
* **Несколько ботов** у одного человека, рассылки, статистика, приём оплаты,
  кнопка «скачать код».

## Проверка

```
python selftest.py
```

Поднимает сервис в памяти, подменяет Telegram заглушкой и проигрывает весь
путь: вход в редактор, сохранение схемы, подключение бота, каждый тип блока,
нажатия кнопок, ответы на вопросы, срабатывание таймера, перенос схем из
прежней версии. Наружу ничего не уходит.

Логика самого полотна проверяется отдельно: скрипт страницы вырезается и
запускается в Node с подставным браузером. Если Node не установлен, этот
раздел пропускается.

Прогнать то же самое на настоящей базе:

```
set TEST_DATABASE_URL=postgresql://...
python selftest.py
```

Тестовые записи после прогона удаляются.

## Запуск у себя на компьютере

```
set BOT_TOKEN=сюда_токен
python main.py
```

Недостающие библиотеки файл доустановит сам. Учтите: мини-апп откроется
только по адресу из интернета — Telegram не умеет открывать `localhost`.
